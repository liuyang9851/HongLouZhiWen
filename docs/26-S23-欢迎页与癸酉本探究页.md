### 3.2 关键设计

**① 数据来自实际跑出的 JSON**

`javascript
const r = await fetch('/data/s22_guiyou.json');
`

该文件由 s22_*.json 系列导出，含：
- unction_words（49 个虚词 × 4 组）
- sentence / ourchar（句长/四字格）
- spearman / dist / ootstrap（聚类与显著性）
- obustness（4 项检验）
- pos.dist / pos.nn（词性分析）

**失败时降级为内置兜底值**（实测数据），保证页面总能显示。

**② 结论必须分三层**

这是本研究最重要的设计 —— 不让读者把"统计显著"误读为"证明了"：

- **第一层 确定的事实**：癸酉本不是曹曹雪芹、也不是高鹗；语法最接近金瓶梅/儒林外史
- **第二层 统计显著但需保留**：字频空间里更近 A（p=0.018），但余弦相反、强度只有 D 的 27.4%
- **第三层 不能推出的**：不能判断"是不是原稿"、不能判断"谁写的"

**③ 必须展示方法错误**

第七章专门写我犯的两次错误：
- 对照语料被现代学术序言污染（导致第一轮 46.4% 判给儒林外史高度可疑）
- 清洗时定位方法错误（砍掉 92% 正文）

> 这一节比结论本身更重要 —— 说明计量研究里**数据核查比算法关键**。

### 4.2 踩的 4 个坑

#### 坑1：模块间共享函数

新页面要用 sc / pi 等 pp.js 内部函数，但它们不是全局。

第一版用 import，报错：
`
ReferenceError: esc is not defined
TypeError: esc is not a function
`

**原因**：ES module 求值顺序 —— page_home.js 加载时 pp.js 还没执行到 window.__HLM__ 赋值。

**解法**：在 pp.js 挂共享对象 + **延迟获取**

`javascript
// app.js
window.__HLM__ = { esc, el, api, get STARTERS(){return STARTERS}, ... };

// page_home.js
const H = () => window.__HLM__ || {};
const esc = (s) => { const f = H().esc; return f ? f(s) : String(s ?? ''); };
`

#### 坑2：/health 路径错误

`
GET http://127.0.0.1:3000/health → 404
`

pi() 只拼接 Node 服务的路径，后端 health 要走代理前缀。

**解法**：pi('/api/backend/health')

#### 坑3：长页面无法滚动

`
.vue { height: 100%; overflow: hidden; }   ← 为聊天等固定高度视图设计
.stage { overflow: hidden; }
`

长内容直接被裁掉，滚轮无效。

**解法**：给两个新页面单独开滚动

`css
.v-home, .v-guiyou {
  height: auto !important;
  min-height: 100%;
  overflow: visible !important;
  display: block !important;
}
.stage:has(.v-home), .stage:has(.v-guiyou) {
  overflow-y: auto;
}
`

#### 坑4：/data/*.json 404

serveStatic 只服务 public/，而 data/ 在它之外。

**解法**：给 server.js 加 /data/ 路由

`javascript
async function serveData(res, urlPath) {
  const rel = decodeURIComponent(urlPath.replace(/^\/data\//, ''));
  if (!/\.json$/.test(rel)) return sendText(res, '403 Forbidden', 403);  // 只允许 json
  const target = path.resolve(DATA_DIR, rel);
  if (!target.startsWith(DATA_DIR)) return sendText(res, '403 Forbidden', 403);
  ...
}
`

### 4.3 缓存处理

给所有本地 js/css 加 ?v=<timestamp>，避免改了代码浏览器还跑旧版。
