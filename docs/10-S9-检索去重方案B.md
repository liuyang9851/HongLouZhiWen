# S9 · 检索去重方案 B（同回次去重）

> 日期：2026-10-24
> 决策：用户在三个方案中选定 **B（融合检索 + 同回次去重）**

---

## 一、问题

三版本进入 RAG 索引后（6,504 chunk），不指定版本时默认**三版本融合检索**。
实测发现两个问题。

### 问题 1：同段落跨版本重复占名额

同一段落在抚琴居本、程高本里都存在，检索时被各召回一次，
占掉 Top-5 里 2~3 个名额，实际只有 1~2 个不同段落可用。

### 问题 2：脂批刷屏（更严重）

实测问「莫失莫忘 仙寿恒昌」：

```
修复前 Top-5：
  第8回 段0-0   fuqinju/pizhu   ← 脂批
  第8回 段0-0   fuqinju/pizhu   ← 脂批
  第8回 段8-18  fuqinju/text    ← 唯一正文
  第8回 段10-12 chenggao/text
  第8回 段0-0   fuqinju/pizhu   ← 脂批
```

**5 个名额里 3 个是第 8 回的脂批**，正文只剩 1 条。

根因：脂批没有段落号（`para_start = -1`），去重键只能用自己的 `chunk_id`，
而每条脂批的 `chunk_id` 都不同 → 永远不会被去重。

---

## 二、方案选择

| 方案 | 行为 | 优点 | 缺点 |
|:---|:---|:---|:---|
| A | 融合检索，不去重 | 覆盖面最广 | Top-5 名额被重复/脂批占用 |
| **B（选定）** | **融合检索 + 同回次去重** | 保留覆盖，名额利用率高 | 需额外逻辑 |
| C | 默认只检索抚琴居本 | 贴近「主链」说法 | 程高/癸酉默认查不到 |

---

## 三、方案 B 的三条规则

```
① 跨版本去重
   同一 (hui, para_start, para_end) 只保留 RRF 最高的那个版本，
   其余版本记为 other_versions（供前端做「跨版本对照」点击）

② 同回正文数量上限
   同一回最多贡献 2 个正文 chunk（MAX_TEXT_PER_HUI = 2）
   → 防止单回刷满 Top-5

③ 脂批名额限制
   同一回最多 1 条脂批（MAX_PZ_PER_HUI = 1）
   脂批总数最多 topk 的一半（MAX_PZ_TOTAL = max(1, topk // 2)）
   → 保证正文始终占主导，脂批只作佐证
```

### 3.1 为什么脂批要限名额

脂批是**解读材料**，不是原文。用户问「莫失莫忘是什么」，
最该先看到的是**正文里那一段**，而不是三条不同的批语都在评论这一段。

脂批应该出现，但不该占据主要名额 —— 这是由内容性质决定的优先级。

### 3.2 为什么「每回 2 条正文」

一个论点通常跨 1~2 个 chunk。给 2 条既能覆盖跨块论点，
又不会让单回把其他回的内容挤掉。

## 五、实现要点

### 5.1 只在「不限版本」时去重

```python
fused = rrf_fuse(kw, vec, graph, CFG["rrf_k"], topk_context,
                 dedup_by_hui=(version is None))
```

用户明确指定版本时（如只查程高本），不存在跨版本重复，无需去重。

### 5.2 `other_versions` 只收不同版本

**踩坑**：第一版把同版本、同段落范围的重复 chunk 也收进 `other_versions`，
前端显示成「+抚琴居校本」—— 自己对照自己，毫无意义。

原因：切分时同一版本内部可能有多个 chunk 覆盖重叠的段落范围。

修法：记录前比对 `kept` 项的版本，只有**版本不同**才收。

### 5.3 debug 暴露去重信息

```json
{
  "dedup_by_hui": true,
  "n_fused": 5,
  "n_other_versions": 2
}
```

## 七、本轮附带修掉的两个数据 bug

### bug 1：癸酉本新旧数据叠加

修正癸酉本回次映射（1-28 → 81-108）后**没有重跑向量化**，
导致 HBase 里同时存在两套数据：

```
guiyouben/text: 1,060 行   回次 {1..28} ∪ {81..108}
```

根因：删除旧数据的条件写的是 `len(parts) == 3`，
但 rowkey 早就是 4 段（`ver|source|hui|cid`），条件永远不成立 → 一行没删。

修法：改为「`src != "pizhu"` 就删除」。
修复后：`guiyouben/text: 530 行，回次 81~108` ✅

### bug 2：指定版本时混入其他版本脂批

在程高本下检索会带出抚琴居本的脂批 ——
程高本是删改本、根本没有脂批，混进来会误导用户。

修法：脂批只在 `version in (None, "fuqinju")` 时参与检索。

实测：
```
[fuqinju]   正文0 脂批5 错版0
[chenggao]  正文5 脂批0 错版0
[guiyouben] 正文5 脂批0 错版0
```
