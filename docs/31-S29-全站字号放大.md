# S29 · 全站字号放大（课堂展示用）

> 日期：2026-10-26
> 需求：「课堂展示时需要更大的文本字体，把 UI 界面除去正文阅读外的所有字的字号放大」

---

## 一、做法：脚本批量缩放，而非逐条手改

全站共 **383 处** `font-size`（CSS 325 + JS 内联 58），逐条手改不现实也容易漏。

写了 `scripts/s29_1_enlarge_fonts.py`，按分段曲线批量放大：

| 原字号区间 | 放大系数 | 理由 |
|:---|:---|:---|
| ≤ 13.5px | **×1.24 + 0.6** | 小字是投影时最看不清的，需要更大幅度 |
| 14 ~ 20px | ×1.15 | 中等字号，线性放大 |
| > 20px | ×1.08 | 标题类，避免溢出 |

### 换算表（实测）

```
 9.0 → 11.5    10.0 → 13.0    10.5 → 13.5    11.0 → 14.0
11.5 → 15.0    12.0 → 15.5    12.5 → 16.0    13.0 → 16.5
13.5 → 17.5    14.0 → 16.0    15.0 → 17.0    16.0 → 18.5
17.0 → 19.5    18.0 → 20.5    20.0 → 23.0    22.0 → 24.0
40.0 → 43.0
```

**典型效果**：正文说明 12px → 15.5px，侧栏导航 13.5px → 17.5px，卡片标题 16px → 18.5px。

### 排除项（正文阅读保持原样）

只排除两个选择器：

| 选择器 | 原字号 | 说明 |
|:---|---:|:---|
| `.rd-paper p` | **16.5px** | 正文段落 |
| `.rd-paper .huimu` | **22px** | 回目大标题 |

**其余全部放大**，包括阅读视图的侧栏目录、工具条、段号标注 —— 这些是 UI 而不是正文。

### 幂等 + 可回滚

- 文件尾部加 `/* S29-FONT-SCALED */` 标记，重复运行不会二次放大
- 每个改动文件都留 `.bak-fs` 备份，`--revert` 可一键还原

```bash
python scripts/s29_1_enlarge_fonts.py --dry     # 只统计
python scripts/s29_1_enlarge_fonts.py           # 执行
python scripts/s29_1_enlarge_fonts.py --revert  # 还原
```

## 二、放大后必须同步调整的布局（关键）

**字号放大必然挤爆原有容器**。实测撞到 4 处，逐一手修：

### 2.1 侧栏导航换行

**现象**：「AI 问答」被挤成「AI 问」+「答」两行，「系统运维」被截断。

**原因**：侧栏 `--rail-w: 168px`，导航字号 13.5px → 17.5px 后，
「AI 问答」+「核心」徽标 + 图标 + 间距 ≈ 158px，超出可用宽度（168 - 20 padding = 148px）。

**修法**：
```css
--rail-w: 168px → 215px;        /* 侧栏加宽 */
--topbar-h: 60px → 68px;        /* 顶栏加高 */
.rail-item .lbl {
  white-space: nowrap;           /* 禁止换行 */
  overflow: hidden;
  text-overflow: ellipsis;       /* 超长省略 */
}
.rail-item .ico { width: 18px → 22px; flex: none; }
```

### 2.2 语料版本表格挤成一团

**现象**：「条数」表头被拆成「条」/「数」两行，「用途」列的 `RAG 主链`、`版本对照` 标签换行，`0-80 回` 也断开。

**原因**：该表用 `col-7`（12 栅格中占 7 列），字号放大后放不下 6 列内容。

**修法**：
```html
<!-- 三版本正文规模表：col-7 → col-12（独占一行） -->
<div class="card col-12">
```
```css
/* 表头与标签禁止换行 */
.table th { white-space: nowrap; }
.table td .tag { white-space: nowrap; }
```

### 2.3 图谱页提示文字被按钮遮挡

**现象**：提示「拖拽空白处平移 · … · 双击空白重置」被右上角的「⟲ 重置」按钮压住。

**修法**：
```css
.gr-tip {
  max-width: calc(100% - 150px);   /* 给重置按钮留位 */
  line-height: 1.65;
}
.gr-reset { z-index: 3; }          /* 按钮提到上层 */
```

### 2.4 图谱图例遮挡

图例字号放大后占位变大，盖住更多画布。实测不影响操作（图例本身 `pointer-events` 正常），保留。

## 六、教训

| # | 教训 |
|:---|:---|
| 1 | **字号和容器尺寸是耦合的**。放大字号必须同步检查侧栏宽度、表格列宽、固定高度，否则一定挤爆。 |
| 2 | **排除项要精确到选择器，不能排除整个模块**。「除去正文阅读」不等于「整个阅读页不动」—— 阅读页的目录/工具条也该放大。 |
| 3 | **批量替换必须做幂等标记**。否则重复运行会二次放大（12px → 15.5 → 19.5）。 |
| 4 | **改样式时逐页核对，能发现数据问题**。这次顺带修了 8 处过期数字，都是靠截图核对发现的。 |
| 5 | **硬编码的展示数据是技术债**。4,563 这个污染值被写死在 4 个 JS 文件里，索引修好了文案却没跟上。 |
