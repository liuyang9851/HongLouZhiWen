# S11 · 原文阅读脂批侧栏滚动修复

> 日期：2026-10-24
> 触发：用户反馈「原文阅读右边的脂批不能滚动」

---

## 一、根因：CSS 类名与 HTML 对不上

**HTML 用的类名**（pp.js）：
`html
<aside class="rd-pizhu" id="pzAside">
  <div class="rd-pizhu-h">…</div>
  <div class="rd-pizhu-list" id="pzBody"></div>   ← 用 rd-pizhu-list
</aside>
`

**CSS 定义的选择器**（iews.css）：
`css
.rd-pizhu-b { flex: 1; overflow-y: auto; padding: 10px; }   ← 写的是 rd-pizhu-b
`

**.rd-pizhu-list 在 CSS 里根本不存在** →
没有 overflow-y: auto → 脂批区高度被内容撑开，无法滚动。

这是重构时改了 HTML 类名但忘了同步 CSS 的典型后果。

---

## 二、第二层原因：flex 子项的 min-height: auto

即使补上 overflow-y: auto，**仍可能不生效**。

CSS 规范：flex 子项默认 min-height: auto，
意味着它**不会收缩到内容高度以下**，于是 overflow: auto 没有可滚动空间。

正确写法必须同时给：
`css
.rd-pizhu-list {
  flex: 1 1 auto;
  min-height: 0;      /* ← 关键，缺这行 overflow 不生效 */
  overflow-y: auto;
}
`

父容器 .rd-pizhu 也要能被约束：
`css
.rd-pizhu {
  display: flex; flex-direction: column;
  min-height: 0;
  height: 100%;
  overflow: hidden;    /* ← 否则内部列表没有高度上限 */
}
`

---

## 三、修复内容

### 3.1 脂批侧栏

`css
.rd-pizhu-list,
.rd-pizhu-b {          /* 两个类名都支持，向后兼容 */
  flex: 1 1 auto;
  min-height: 0;
  overflow-y: auto;
  overflow-x: hidden;
  padding: 10px;
  scrollbar-width: thin;
  overscroll-behavior: contain;
}
`

同时补了滚动条样式（细滚动条 + hover 加深）。

### 3.2 顺带修的回目列表

.rd-list 原来只有 lex: 1; overflow-y: auto;，
同样缺 min-height: 0。一起加固。

## 六、教训

| # | 教训 |
|:---|:---|
| 1 | **改 HTML 类名必须同步 CSS**。这次是 d-pizhu-b → d-pizhu-list 的单向改名，CSS 没跟上。 |
| 2 | **overflow: auto 不够，还要 min-height: 0**。flex 子项的默认 min-height: auto 会让 overflow 完全失效，这是最容易漏的一条。 |
| 3 | **父容器也要参与约束**。子项能滚的前提是父容器有确定高度且不溢出。 |
| 4 | **同类问题要一次扫完**。发现一个缺 min-height 就该审计全部，而不是等用户一个个报。 |
