### 1.2 状态切换

| 状态 | 按钮文字 | 样式 | title |
|:---|:---|:---|:---|
| 非全屏 | **⛶ 全屏** | 普通 | 进入全屏（Esc 退出）|
| 全屏中 | **⛶ 退出全屏** | 红色高亮 | 退出全屏（Esc）|

### 1.3 核心逻辑

```javascript
function initFullscreen() {
  const btn = document.getElementById('btnFullscreen');
  if (!btn) return;

  const isFs = () => !!(document.fullscreenElement ||
                        document.webkitFullscreenElement ||
                        document.msFullscreenElement);

  async function enter() {
    const el = document.documentElement;      // 整个页面进全屏
    try {
      if (el.requestFullscreen) await el.requestFullscreen();
      else if (el.webkitRequestFullscreen) el.webkitRequestFullscreen();
      else if (el.msRequestFullscreen) el.msRequestFullscreen();
      else { toast('当前浏览器不支持全屏'); return; }
      toast('已进入全屏，按 Esc 退出');
    } catch (e) {
      toast('进入全屏失败：' + (e.message || e));
    }
  }

  async function exit() {
    if (document.exitFullscreen) await document.exitFullscreen();
    else if (document.webkitExitFullscreen) document.webkitExitFullscreen();
    else if (document.msExitFullscreen) document.msExitFullscreen();
  }

  btn.onclick = () => (isFs() ? exit() : enter());

  // 状态同步 —— 含用户按 Esc / F11 退出
  ['fullscreenchange', 'webkitfullscreenchange', 'MSFullscreenChange']
    .forEach((ev) => document.addEventListener(ev, sync));

  sync();
}
```

### 1.4 三个关键设计点

**① 用 `document.documentElement` 而非某个容器**

全屏整个页面，顶栏也保留 —— 这样用户在全屏时仍能看到模型选择、后端状态、退出按钮。

**② 监听 `fullscreenchange` 而不是只靠点击**

用户可能用 **Esc** 或 **F11** 退出全屏，此时按钮状态必须跟着变。
监听事件是唯一可靠的方式。

**③ 全屏后 dispatch resize 事件**

```javascript
window.dispatchEvent(new Event('resize'));
```

图谱页的 Canvas 是按容器尺寸绘制的。全屏后容器尺寸变了，
如果不通知，画布会保持旧尺寸，出现留白或拉伸。

### 1.5 跨浏览器兼容

三个前缀都做了 fallback：

| API | 标准 | WebKit | IE/旧 Edge |
|:---|:---|:---|:---|
| 进入 | `requestFullscreen()` | `webkitRequestFullscreen()` | `msRequestFullscreen()` |
| 退出 | `exitFullscreen()` | `webkitExitFullscreen()` | `msExitFullscreen()` |
| 状态 | `fullscreenElement` | `webkitFullscreenElement` | `msFullscreenElement` |

## 四、使用说明（课堂演示）

```
1. 打开 http://127.0.0.1:5173
2. 点右上角「⛶ 全屏」
3. 投影演示
4. 结束时按 Esc，或点「⛶ 退出全屏」
```

**注意**：浏览器全屏（`requestFullscreen`）与 F11 全屏是两套机制。
本功能用标准 Fullscreen API，优点是可以精确控制何时进入/退出，
且按钮状态始终可见。
