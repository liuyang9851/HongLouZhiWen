### 配套的布局调整

字变大后容器必须跟着变，否则会换行错乱：

```css
/* 卡片最小宽度：6 张卡在 1124px 内单行排列 */
.hp-data { grid-template-columns: repeat(auto-fit, minmax(190px → 168px, 1fr)); }

/* 表格行高（字号变大后不那么挤） */
.hp-vers tbody td { padding: 8px → 10px 8px; }
.hp-vers tfoot td { padding: 9px 8px 2px → 11px 8px 3px; }
```

> 第一次设 190px 时，第 6 张卡被挤到第二行单独占一行 —— 视觉上很不平衡。
> 调到 168px 后 6 张卡正好单行。

### 2.2 图谱数字过期

`page_home.js` 里写死「350 人物 / **676** 条关系」「**676** 条边 / **121** 种关系」，
实际是 674 边 / 120 种。

**改成动态读取**：

```javascript
let graph = null;
try { graph = await api('/api/graph'); } catch (e) {}
const nGNode = graph?.n_nodes ?? 350;
const nGEdge = graph?.n_edges ?? 674;
const nGRel = (graph?.relations || []).length || 120;
```

以后图谱变了不用再改代码。

### 2.3 脂批数字又一次过期

`9,854`（三源去重总数，应为 8,510）、`4,563`（抚琴居脂批，应为 3,219）在多处重新出现。

这与之前索引被旧脚本污染是同一批问题：索引修好了，硬编码文案没跟上。

已全部修正，并**扩展了 `s32` 校验脚本**，现在会检查这三个历史遗留值：

```python
for old_v, new_v in (("9,854", "8,510"), ("4,563", "3,219"), ("5,754", "5,069")):
    if old_v in src:
        src = src.replace(old_v, new_v)
        problems.append(f"{name}: 脂批数字 {old_v} → {new_v}")
```

## 三、⚠️ 意外：`chord` 函数丢失，首页白屏

改字号后页面卡在「正在载入语料…」，控制台报：

```
SyntaxError: The requested module './chart3d.js'
does not provide an export named 'chord'
```

### 排查

| 检查 | 结果 |
|:---|:---|
| `app.js:16` | `import { force3d, surface3d, chord } from './chart3d.js'` |
| `chart3d.js` 导出 | 只有 `force3d`、`surface3d` —— **`chord` 没了** |
| 文件修改时间 | `2026-10-26 13:15:59`（就在请求前）|
| 全盘搜索副本 | 只有这一个文件 |
| 备份 / git | 无 `.bak`，项目不在 git 里 |

**整个首页白屏**，因为 ES Module 的 import 失败会中断整个模块图 ——
一个函数丢失，整站不可用。

### 修复：按调用约定重建

从调用处反推接口：

```javascript
inst = chord(fresh, M, fams, {});
// fresh: canvas 元素（克隆的）
// M:     N×N 对称矩阵，M[i][j] = 家族 i 与 j 的关系条数
// fams:  家族名数组
// 返回:  { destroy() }
```

提示文案给了设计约束：

> 悬停扇区看该家族 · 弦宽=两家关系条数 · 环内为同族关系

### 实现要点

| 步骤 | 做法 |
|:---|:---|
| 布局 | 每个家族按「关系总数」占比分配弧长，扇区间留 0.022 弧度空隙 |
| 扇区内细分 | 按 `M[i][j] / total_i` 再切子区间，供弦带精确对齐 |
| 弦带 | 二次贝塞尔连到圆心，宽度即子区间宽度（∝ 关系条数）|
| 族内关系 | 用内侧细弧表示（半径 −12，圆头），不画弦 |
| 外环 | 环形扇区 + 家族名 + 条数（径向偏移 22，自动左/右/居中）|
| 悬停 | 按角度反查扇区，高亮该家族、其余淡出，中心显示族名与总数 |
| DPR | `min(devicePixelRatio, 2)`，`setTransform` 保证清晰 |

**结果**：和弦图恢复正常，6 个家族（贾 105 / 其他 112 / 史 18 / 王 13 / 薛 22 / 林 …）
弧长按关系数分配，弦带连接正确。

## 六、教训

| # | 教训 |
|:---|:---|
| 1 | **一个缺失的 export 能让整站白屏**。ES Module 的 import 失败会中断整个模块图，UI 没有任何提示，只有控制台有错误。 |

| 3 | **字号和容器宽度必须同步调**。表格 12→16 后行高、内边距、卡片最小宽度都要跟着改。 |
| 4 | **硬编码数字是持续污染源**。这次又发现 9,854 / 4,563 / 676 三批过期值 —— 能动态化的（图谱）已动态化，改不动的靠 s32 校验兜底。 |
