# S22 · 癸酉本真伪的定量研究

> 日期：2026-10-24
> 研究问题：网络上对「癸酉本」是否为真本争论激烈。能否用统计方法定量地看这个问题？

---

## 零、先看网络上的争论焦点

搜索结果里，双方核心论点很清晰：

**反对方**（[中国作家网《癸酉本：大众红学盛开的恶之花》](http://www.chinawriter.com.cn/n1/2023/0814/c442005-40055736.html)、[知乎「六大硬伤」](https://zhuanlan.zhihu.com/p/2071715049689896420)）：
- 语言风格与曹雪芹前 80 回差异巨大
- 词汇时代错误（出现晚清民国才有的词）
- 文笔粗劣，大量现代白话
- 情节过度"对号入座"脂批

**支持方**（[维基百科·吴氏石头记增删试评本](https://zh.wikipedia.org/wiki/%E5%90%B3%E6%B0%8F%E7%9F%B3%E9%A0%AD%E8%A8%98%E5%A2%9E%E5%88%AA%E8%A9%A6%E8%A9%95%E6%9C%AC)）：
- 108 回完整体量符合周汝昌推论
- 后 28 回大量呼应前文脂批暗示
- 末回给出「情榜」，与前文伏笔吻合

**关键观察**：双方都在说"语言风格"，但都是**印象式判断**。
知乎上确有[词频分析的民科尝试](https://wapbaike.baidu.com/tashuo/browse/content?id=f39dc6c702d32340797679d1)，但方法粗糙。

**本项目能做的是：用成熟的计量风格学（stylometry）方法，给出可复现的定量结果。**

---

## 一、实验设计

### 1.1 三组对照 + 一个校验组

| 组 | 语料 | 体量 | 作者 | 作用 |
|:---|:---|---:|:---|:---|
| **A** | 抚琴居本 1-80 回 | 80 回 / 593,437 字 | 曹雪芹（公认） | **基准1：真** |
| **B** | 程高本 81-120 回 | 40 回 / 277,790 字 | 高鹗续书（公认） | **基准2：已知非曹雪芹** |
| **C** | 癸酉本 81-108 回 | 28 回 / 217,059 字 | 争议 | **待测** |
| **D** | 程高本 1-80 回 | 80 回 / 591,692 字 | 曹雪芹（版本不同） | **校验：同作者异版本的差异尺度** |

**D 组是整个实验的关键** —— 它告诉我们"同一个作者、不同版本"能有多大差异。
如果 C 与 A 的差异不超过 D 与 A 的差异，那 C 就"不出格"。

### 1.2 特征集（39 维）

| 类别 | 特征数 | 说明 |
|:---|---:|:---|
| 虚词频率 | 30 | 的/了/着/把/被/将/之/其/而/则/也/都/又/便/却/只…（每万字归一） |
| 句长分布 | 4 | 均值/标准差/短句比例/长句比例 |
| 标点节奏 | 3 | 每百字标点数/逗号比/句号比 |
| 词汇丰富度 | 1 | TTR（固定窗口） |
| 四字格密度 | 1 | 每万字成语式短语数 |

**为什么用虚词为主**：虚词使用频率是作者的"潜意识指纹"，最难伪装。
模仿情节容易，模仿「把/被」用多少极难。

## 二、描述性结果

### 2.1 虚词频率（每万字）—— 先看最直观的

| 虚词 | A 曹雪芹 | B 高鹗 | C 癸酉本 | C 更近 |
|:---:|---:|---:|---:|:---:|
| 的 | 170.85 | 198.57 | **138.81** | A |
| 了 | 240.24 | 250.26 | 255.05 | B |
| 着 | 63.55 | 85.57 | 82.51 | B |
| 把 | 11.95 | 15.59 | **29.53** | ✗ 都不是 |
| **被** | 2.73 | 4.43 | **18.57** | ✗ 严重偏离 |
| 将 | 13.04 | 13.57 | 7.83 | A |
| 之 | 30.21 | 11.66 | 21.88 | A |
| 其 | 6.05 | 2.05 | 5.07 | A |
| 便 | 44.00 | 53.28 | **15.25** | ✗ 严重偏离 |
| 只 | 52.47 | 56.52 | 34.69 | A |

**两个刺眼的异常**：

1. **「被」字：癸酉本 18.57 次/万字，是曹雪芹的 6.8 倍、高鹗的 4.2 倍**
2. **「把」字：癸酉本 29.53 次/万字，是曹雪芹的 2.5 倍**

这是一个**极其重要的发现**：
《红楼梦》前 80 回极少用「被」字（2.73/万字），因为曹雪芹惯用「叫/让/给」式被动；
现代汉语式「被」字句大规模使用，是**晚清以后白话文运动**才普及的。

**这与反对派说的"词汇时代错误"完全吻合，而且第一次给出了量化证据。**

### 2.2 句长分布

| 指标 | A | B | C |
|:---|---:|---:|---:|
| 平均句长 | 24.26 | 23.63 | **30.99** |
| 标准差 | 15.07 | 14.14 | **23.77** |
| 长句比例（≥40字） | 13.06% | 11.93% | **23.17%** |
| 短句比例（≤8字） | 7.09% | 7.56% | **4.99%** |

**癸酉本句子明显更长、波动更大、短句更少。**
曹雪芹和高鹗在这一点上高度一致（24.26 vs 23.63），癸酉本却跳出这个区间（30.99）。

### 2.3 四字格密度（成语使用）

| 组 | 四字格/万字 |
|:---|---:|
| A 曹雪芹 | **215.05** |
| B 高鹗 | 184.35 |
| C 癸酉本 | **157.61** |

癸酉本的成语密度只有曹雪芹的 **73%**。

### 2.4 字频秩相关 / 高频词重叠（与 A 组比较）

| 对照组 | Spearman 秩相关 | 高频 500 字 Jaccard |
|:---|---:|---:|
| **D 程高本前80回**（同作者） | **0.9924** | **0.9881** |
| B 高鹗后40回 | 0.7491 | 0.7036 |
| C 癸酉本 | 0.7379 | 0.6750 |

**注意**：C（0.7379）比 B（0.7491）**略低**。
即按字频排序，癸酉本离曹雪芹的距离，比高鹗续书还要远一点点。

## 三、推断性结果（这一节才是结论）

### 3.1 质心距离：C 更近谁？

| 距离度量 | C→A（曹） | C→B（高） | 更近 | D→A（同作者基准） |
|:---|---:|---:|:---:|---:|
| 欧氏 | 6.5548 | 7.4076 | **A** | 0.2417 |
| 曼哈顿 | 32.1521 | 37.3610 | **A** | 0.9437 |
| 余弦 | 1.7208 | 1.3886 | **B** | 0.0249 |

**⚠️ 这里出现了矛盾**：欧氏/曼哈顿说更像 A，余弦说更像 B。

这种矛盾必须诚实报告。它说明：**结论依赖距离度量**，不能只看一个数字。

### 3.2 bootstrap 显著性

随机抽 20 回，重复 2000 次：

```
距离差 = dist(C,B) - dist(C,A)    正数=更像 A

均值:        +0.8495
95% 置信区间: [+0.6748, +1.0061]     ← 不含 0
P(更像 A) = 100.0%
P(更像 B) = 0.0%

→ 显著更像 A（曹雪芹）
```

### 3.3 最近邻分析：每一回单独判

把 C 的 28 回逐个拿去和 A∪B 的 120 回比，找最近的：

```
最像 A（曹雪芹）: 25 回 (89.3%)
最像 B（高鹗）  :  3 回 (10.7%)
```

### 3.4 稳健性检验（决定结论可不可信）

这一节是对上面结论的"压力测试"。

#### 检验1：留一特征（去掉任一特征重跑）

```
结论翻转的特征数: 0 / 39
✅ 去掉任一特征都不翻转 → 结论稳健
```

影响最大的特征（去掉后差值变化）：

| 特征 | 去掉后差值 | 变化 |
|:---|---:|---:|
| period_r（句号比） | +0.6880 | −0.1648 |
| fw_被 | +1.0101 | +0.1573 |
| fw_把 | +0.9751 | +0.1223 |
| four_per10k（四字格） | +0.9741 | +0.1213 |

**没有任何单一特征能独力决定结论。**

#### 检验2：只用虚词（去掉句长/标点等"可模仿"特征）

```
虚词特征数: 30
只用虚词的距离差: +0.6828  → 更像 A
（全特征: +0.8529）
对照 D: +2.9393
```

**只用最难伪装的虚词，结论方向不变。**

#### 检验3：置换检验（真正的 p 值）

随机打乱 A/B/C 标签 1000 次：

```
观测差值:        +0.8529
置换分布 95% 分位: +0.7334
置换分布最大值:   +1.4144
p 值 = 0.018

✅ p < 0.05，结论显著
```

**p = 0.018 意味着：纯随机情况下，只有 1.8% 的概率能得到这么极端的距离差。**

#### 检验4：混淆检验（方法有效性）

把 D（程高本前80回，确实是曹雪芹）当作待测组：

```
D 的距离差: +3.1182 → 更像 A ✅   （方法有效）
C 的距离差: +0.8529
C / D 比值: 0.274
```

**这一项最有信息量**：
- 方向一致（都更近 A）→ 方法本身没问题
- 但 C 的差值只有 D 的 **27.4%** → 癸酉本与曹雪芹的相似度，**明显低于**同作者不同版本的相似度

## 四、结论（分三层，逐层降确定性）

### 第一层：确定的事实

1. **癸酉本在多项统计指标上，都不落在「曹雪芹-高鹗」的共同区间内**
   - 平均句长 30.99 vs 曹 24.26 / 高 23.63
   - 「被」字频次 18.57 vs 曹 2.73 / 高 4.43
   - 「把」字频次 29.53 vs 曹 11.95 / 高 15.59

2. **「被」字异常是最硬的证据**
   - 癸酉本是曹雪芹的 **6.8 倍**
   - 「被」字式被动在晚清白话文中才普及
   - 这与反对派"词汇时代错误"的论点吻合，且首次量化

3. **癸酉本的作者，与曹雪芹、高鹗都不是同一人**
   - 若同一人，D 组（0.9924 秩相关）才是正常水平
   - C 组 0.7379 与 B 组 0.7491 相当，远低于 D

### 第二层：统计上显著，但需谨慎表述

4. **在 39 维特征空间里，癸酉本离曹雪芹比离高鹗稍近**
   - 欧氏/曼哈顿距离支持
   - bootstrap 95%CI 不含 0
   - 置换检验 p = 0.018
   - 最近邻 89.3% 判给 A

5. **但这个"稍近"的程度很有限**
   - C 的差值只有 D 的 27.4%
   - 字频秩相关上 C（0.7379）甚至略低于 B（0.7491）
   - 余弦距离给出相反结论

### 第三层：不能从统计推出的

6. **统计不能判断癸酉本"是不是曹雪芹原稿"**
   能判断的是：**它的语言不是曹雪芹晚年的语言**。

7. **统计不能判断癸酉本是"真本"还是"伪作"**
   能判断的是：**它经过了与曹雪芹不同的书写过程**。

## 五、我的解读（明确标注为主观）

综合以上，**最符合数据的假设是**：

> 癸酉本后 28 回**不是曹雪芹的原稿，也不是高鹗的续书**，
> 而是**另一个（或一组）后人**在熟悉前 80 回与脂批的基础上创作的续书。

支持这个假设的具体证据：

| 证据 | 指向 |
|:---|:---|
| 「被」「把」字频次是现代白话特征 | 写作年代晚于曹雪芹 |
| 句长比曹、高都长且波动大 | 书写习惯不同 |
| 四字格密度只有曹的 73% | 古典文学功底不同 |
| 但与曹雪芹的距离 < 与高鹗的距离 | 作者**刻意模仿**前 80 回 |
| 情节高度呼应脂批 | 作者**熟读脂批**，按批语"填空" |

**这个组合恰好解释了双方各自的观察**：
- 支持方看到的"情节吻合脂批"是真的
- 反对方看到的"语言不像曹雪芹"也是真的

两者并不矛盾 —— **一个熟读脂批的现代人，完全可以写出一部"情节处处照应前文"但"语言完全不像曹雪芹"的续书**。

## 六、局限（必须说明）

| # | 局限 | 影响 |
|:---|:---|:---|
| 1 | **余弦距离给出相反结论** | 结论依赖度量选择，不是 100% 稳健 |
| 2 | 39 维特征仍是有限集 | 未覆盖词性标注、依存句法、用字偏好等 |
| 3 | 癸酉本只有 28 回样本 | 统计功效受限（A 有 80 回，B 有 40 回）|
| 4 | 未做「历时变化」控制 | 曹雪芹写作前80回跨十余年，语言本身有漂移 |
| 5 | 未与明清其他小说对比 | 无法判断"癸酉本风格"是否是某类通俗小说的常态 |
| 6 | **统计只能证伪"同一作者"，不能证明"谁写的"** | 归因需要额外证据 |

### 第 1 条最需要正视

我做了 4 个稳健性检验，3 个支持"更像曹雪芹"，但**余弦距离始终相反**。
诚实地讲：**这个结论是"倾向于"，不是"证实"。**

## 九、一句话总结

> **癸酉本的语言不是曹雪芹的，也不太像高鹗；它像是一个熟读前 80 回与脂批的后人，努力模仿前文写出的续书。**
>
> 统计上：离曹雪芹比离高鹗稍近（p=0.018），但相似度只有同作者异版本的 27%。
> 最硬的单点证据是「被」字频次 —— 曹雪芹的 6.8 倍，这是现代白话的特征。
