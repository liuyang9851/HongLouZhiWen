# S16 · 癸酉本批语接入阅读界面侧边栏

> 日期：2026-10-24
> 触发：用户反馈「癸酉本没有侧边栏的批语，补上」

---

## 一、问题定位

### 1.1 三层都有问题

| 层 | 问题 |
|:---|:---|
| **数据层** | `web/data/pizhu.json` 只有一个全局 `by_hui`，**只含抚琴居批语**（79 回 / 1–80 回） |
| **生成层** | `s7_3_build_webdata.py` 只给 `fuqinju` 写 `pizhu` 字段，癸酉本章节 JSON 里**连这个字段都没有** |
| **渲染层** | `app.js` 第 1115 行硬编码 `if (ver !== 'fuqinju') aside.style.display = 'none'` → **直接隐藏** |

三层叠加的结果：癸酉本批语虽然已进 RAG 索引（222 chunk），但阅读界面完全看不到。

### 1.2 关键代码（修复前）

```javascript
// app.js
if (ver !== 'fuqinju') {
  aside.style.display = 'none';     // ← 非抚琴居一律隐藏
}
```

```python
# s7_3_build_webdata.py
if ver == "fuqinju":                # ← 只有抚琴居写 pizhu
    obj["pizhu"] = pizhu_by_hui.get(str(hui), [])
```

---

## 二、修复方案

### 2.1 数据层：按版本分组

`pizhu.json` 从「单一全局表」改为「按版本分组」：

```json
{
  "by_version": {
    "fuqinju":   { "by_hui": { "1": [...], "78": [...] } },
    "guiyouben": { "by_hui": { "81": [...], "105": [...] } },
    "chenggao":  { "by_hui": {} }
  },
  "by_hui": { ... },        // 向后兼容，指向 fuqinju
  "note": "..."
}
```

新增脚本 `scripts/s16_build_pizhu_by_version.py`：

| 版本 | 数据源 | 条数 | 说明 |
|:---|:---|---:|:---|
| `fuqinju` | `码点核对/pizhu_redecoded.jsonl` | 1,443（每回上限 30） | 79 回 |
| `guiyouben` | `hlm_corpus/guiyouben/pizhu.jsonl` | 223 | 47 回（含 1–80 回摘录） |
| `chenggao` | 无 | 0 | 删改本无脂批 |

### 2.2 生成层：按版本写入

```python
# s7_3_build_webdata.py
for ver, ... in versions.items():
    ...
    # 每个版本都写入自己的批语（癸酉本 223 条 / 程高本空）
    _pz_for_ver = pizhu_by_ver.get(ver, {})
    obj["pizhu"] = _pz_for_ver.get(str(hui), [])
    obj["pizhu_source"] = ("癸酉本" if ver == "guiyouben"
                           else ("程高本（删改本，无脂批）" if ver == "chenggao"
                                 else "抚琴居校本"))
```

### 2.3 渲染层：按版本显示不同批语

```javascript
const VER_PZ_NAME = {
  fuqinju:   '脂批',
  guiyouben: '癸酉本批语',
  chenggao:  '批语',
};
// 侧栏标题随版本变化
if (pzTitle) pzTitle.textContent = VER_PZ_NAME[ver] || '批语';

// 不再隐藏，而是按情况显示
aside.style.display = '';
if (!pz.length) {
  const why = ver === 'chenggao'
    ? '程高本是删改本，<b>没有脂批</b>。<br>脂批仅见于脂评本系统（甲戌/庚辰/蒙府等）。'
    : '本回无批语记录。';
  body.innerHTML = `<div class="muted">${why}</div>`;
}
```

**程高本的处理很关键**：不是静默隐藏，而是**明确告知为什么没有**。
用户看到空白侧栏会以为是 bug，写明「删改本无脂批」才是正确做法。

### 3.2 按回次

| 范围 | 条数 | 是否在癸酉本阅读界面显示 |
|:---|---:|:---|
| **81–108 回** | **103** | ✅ 显示（癸酉本正文范围） |
| 1–80 回（前80回摘录） | 120 | ❌ 不显示（癸酉本正文不含这些回） |

**这是正确行为**：那 120 条是癸酉本对前 80 回的**摘录**，
挂在 hui=1..80 上，而癸酉本正文只有 81–108 回，所以阅读时自然不出现。
它们仍在 RAG 索引里（`guiyouben/pizhu` 222 chunk），检索时可用。

### 4.2 三版本对照

| 版本 | 侧栏标题 | 第78回/105回批语数 | 标签 |
|:---|:---|---:|:---|
| 抚琴居校本 | 脂批 | 30 条（第78回） | 抚琴居校本 + 蒙府本 + p.2087 |
| 癸酉本 | **癸酉本批语** | 16 条（第105回） | 癸酉本 + 内嵌批 |
| 程高本 | 批语 | 0 条 | 显示说明：「程高本是删改本，**没有脂批**」 |

### 4.3 版本标签去重

**踩的坑**：第一版把 `src_tag="癸酉本"` 和 `versions=["癸酉本"]` 各渲染一次
→ 出现两个「癸酉本」标签。

修法：用 `Set` 去重。

```javascript
const seenTags = new Set();
const tagHtml = [];
if (p.src_tag) { tagHtml.push(green(src_tag)); seenTags.add(p.src_tag); }
for (const v of (p.versions || [])) {
  if (seenTags.has(v)) continue;      // ← 去重
  seenTags.add(v);
  tagHtml.push(red(v));
}
```

## 六、教训

| # | 教训 |
|:---|:---|
| 1 | **「隐藏」是逃避问题，不是解决**。旧代码 `aside.style.display='none'` 一行为，把「不同版本有不同的批语数据」这个真实需求变成了「非主版本不显示批语」。 |
| 2 | **没有数据 ≠ 不该显示**。程高本确实没有脂批，但应该**说明原因**（删改本），而不是给用户一个空白或消失的侧栏。 |
| 3 | **数据链要按维度检查**。`pizhu.json` 是「版本无关」的单表结构 —— 从一开始就埋了坑，等到第二、三版本接入才暴露。 |
| 4 | **标签重复是小坑但显眼**。`src_tag` 和 `versions` 语义重叠，渲染时不注意就会出双标签。 |
