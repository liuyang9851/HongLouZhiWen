## 一、脂批大全前缀噪音：131 条纯标注删除，117 条保留正文

### 1.1 噪音是什么

看 PDF 原文（脂批大全 简体版，第 15 页）：

```
〖甲眉、觉双〗
一段妻妾迎新送死，倏恩倏爱、倏痛倏悲，缠绵不了。〖甲眉〗
（〖觉双〗死~故）                       ← 校勘标注，独立一行
一段石火光阴，悲喜不了；风露草霜，富贵嗜欲，贪婪不了。〖甲眉〗
（〖觉双〗风露~一段风露）               ← 校勘标注
一段儿女死后无凭，生前空为筹划计算，痴心不了。〖甲眉、觉双〗
```

`X~Y` 的含义是「**底本作 X，校本改作 Y**」。
它是**独立的行间标注**，不属于批语正文。

旧提取脚本按「批语一行」切分，把标注和下一行批语粘在一起：

```
死~故)一段石火光阴，悲喜不了；风露草霜，富贵嗜欲，贪婪不了。
└─标注─┘└────────────── 批语正文 ──────────────┘
```

### 1.2 三类形态

| 类型 | 条数 | 样例 | 处置 |
|:---|---:|:---|:---|
| **纯标注**（无正文） | 131 | `璧~壁`、`借用 ~ 借)(`、`警句~惊句` | **整条删除** |
| **标注 + 正文** | 117 | `死~故)一段石火光阴…` | **只删前缀，保留正文** |
| 中间/结尾含 `~` 但有正文 | 118 | `族大人〜□□□ ,明〜□ ,则〜□ ,文字 ~ 文事)(…` | **保留原样**（标注嵌在正文中间，无法安全切分） |

### 1.3 三次失败与最终方案

这个清理我做了 4 个版本，前 3 个都是错的，记录在此：

| 版本 | 做法 | 错误 | 后果 |
|:---|:---|:---|:---|
| v1 | 用「长度短」判断残渣 | 短 ≠ 残渣。古籍批语大量是 2~5 字短批 | **误删 617 条**（「伏笔。」「细。」「妙在"无考"。」） |
| v2 | 清理后仍判残渣 → 整条删 | 「标注+正文」的正文被一起删了 | **误删 316 条正文** |
| v3 | 加尾部清理，正则过宽 | 清理后反而冒出 122 条新噪音 | 无净收益 |
| **v4（最终）** | **只做两件确定安全的事** | — | **删除 131，改写 117，零误删** |

**v4 的核心原则：宁可少修，不可误删。**

```python
# ① 纯标注（整条就是 X~Y / X~Y)(，无正文）→ 删
RE_PURE = re.compile(r'^\s*[(（]?\s*' + JK_BODY + r'\s*[)）]?\s*[(（]?\s*$')

# ② 标注前缀（后面有实质正文）→ 只删前缀
RE_PREFIX = re.compile(r'^\s*[(（]?\s*' + JK_BODY + r'\s*[)）]\s*')

# ③ 其余含 ~ 的 → 不动
```

正文保留门槛经过实测校准：

| 剩余内容 | 判定 | 依据 |
|:---|:---|:---|
| ≥4 字 | 有效 | `精工之极。`(5字) |
| 2~3 字 + 有句末标点 | 有效 | `是蕉。`、`也好。` |
| 只有数字/符号 | 无效 → 删 | `识~知)3` |

### 1.4 零误删验证

对全部 131 条删除项逐条检查「去掉标注后还剩多少汉字」：

```
剩余汉字 >3 的（可能误删）: 0 条
✅ 零误删
```

## 五、本轮教训

| # | 教训 |
|:---|:---|
| 1 | **「短」不等于「噪音」**。古籍批语大量是 2~5 字（「伏笔。」「细。」），用长度做残渣判定会灾难性误删。 |
| 2 | **清理和删除要分开**。「标注+正文」只能删前缀，不能整条删 —— 我第二次就栽在这里。 |
| 3 | **每改一次都要回滚验证**。我第 3 版加尾部正则后，「复查噪音」从 68 涨到 122，说明改坏了。有备份才敢试。 |
| 4 | **最终用最保守的方案**。只处理能 100% 确定的两类（纯标注删、前缀删保留正文），其余 118 条不动 —— 它们虽然有 `~`，但标注嵌在正文中间，切分风险大于收益。 |
| 5 | **文档数字要区分「历史事实」与「当前状态」**。MapReduce 的 1,035 是当时的输入，不该改；索引总量才是当前状态。 |
