## 一、脂批大全：中间混入校勘标注

### 1.1 问题形态

S14 处理了两类（纯标注删除 131 条、开头前缀删除 117 条），
剩 118 条是**标注混在中间**：

```
族大人〜□□□ ,明〜□ ,则〜□ ,文字 ~ 文事)(           ← 全是标注，无正文
荣府 ~ 荣府正人,然后一一〜一一,奴仆〜一仆,…)(
〔疒赘〕瘰 ~ 累赘)开笔即写贾夫人已死,是特使黛玉入荣之速也。(   ← 标注 + 正文
身世~身分。)补尼道一段,又伏一案。                      ← 标注 + 正文
```

### 1.2 关键洞察

**标注段总是以 `)` 或 `）` 结束，`)` 之后才是正文。**
（PDF 里 `（〖觉双〗X~Y）` 是完整的一行，转文本时左括号常丢、右括号留下。）

### 1.3 修复规则

```
输入:  X~Y,Z~W)正文
       └── 前缀标注 ──┘
输出:  正文
```

安全阀：
- `)` 前必须出现过 `~`（确认是标注而非正文里的括号）
- `)` 后有实质正文（≥4 字，或 2~3 字但含句末标点）
- 无分隔符时用启发式：开头连续含 `~` 的逗号段是标注，第一段不含 `~` 的是正文

### 1.4 结果

| 项 | 数量 |
|:---|---:|
| 删除（无正文） | **25 条** |
| 裁掉标注保留正文 | **92 条** |
| 保持原样（编者说明） | **1 条** |
| **条数变化** | 9,025 → **9,000** |

## 三、抚琴居：短批语续接（13 → 18 条）

### 3.1 剩余 35 条短批语

它们的共同特征：以「，」或「之/是/此」结尾，说明后面还有文字，
但都没超过 30 字，所以 S15-2 没处理。

### 3.2 三次尝试

| 版本 | 做法 | 结果 |
|:---|:---|:---|
| v1 | 锚点后收集楷体，遇同行宋体就 `break` | 15 条 |
| v2 | 遇同行宋体改为「跳过继续」 | 15 条（无改善） |

### 3.5 加了「防误合并」三道阀

自动续接有把「独立的下一行批语」误合并的风险。加了三条否决：

| 阀 | 规则 | 拦截样例 |
|:---|:---|:---|
| ① | 原文以 `：` 结尾 → 后面是引文，属另一条 | `谚云：` + `"一日卖了三千假…"信哉！` |
| ② | 续文以引号/书名号开头 → 独立内容 | `"一日卖了三千假…"` |
| ③ | 续文以 `◇` 开头 → 明确的批语分隔符 | `◇这是第一次算还…` |

## 九、教训

| # | 教训 |
|:---|:---|
| 1 | **右括号是关键锚点**。`X~Y)` 里的 `)` 是 PDF 里标注行的结束符，靠它才能安全切分「标注 / 正文」。 |
| 2 | **双行夹批夹在正文行之间**。遇到正文就结束会漏掉续文 —— 必须继续往后扫。 |
| 3 | **不是所有「以逗号结尾」都是截断**。原书确实存在独立成条的短批（`奇奇怪怪，`），强行合并会破坏批语边界。 |
| 4 | **自动续接必须加防误合并阀**。`谚云：` + 引文是最典型的陷阱。 |
| 5 | **定向修复时要用 PDF 字体做交叉验证**。批语是 KaiTi、正文是 SimSun，只取 KaiTi 就能确认是不是批语原文。 |
