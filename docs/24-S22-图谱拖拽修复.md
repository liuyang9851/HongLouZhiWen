# S22 · 修复：人物关系图拖拽移动不可用

> 日期：2026-10-24
> 反馈：「人物关系界面的拖拽移动功能不可用，修复一下」

---

## 一、根因（三个问题叠加）

### 问题1：画布平移功能**根本没写** ⭐ 主因

界面提示写着「**拖拽移动**」，但代码里只实现了「拖拽节点」，**拖拽空白处平移画布完全没实现**。

证据 —— 全文搜 `view.x = `：

```
525: view.x = mx - ((mx - view.x) * nk) / view.k;   ← 滚轮缩放里
526: view.y = my - ((my - view.y) * nk) / view.k;   ← 滚轮缩放里
```

**只有滚轮那两行**，没有任何拖拽平移的赋值。

用户拖拽空白处时，代码只做了 hover 判断（`pick(p)` 返回 null），什么都没发生。

### 问题2：`mousemove` 绑在 canvas 上，不是 window

```javascript
canvas.addEventListener('mousemove', ...)   // ← 鼠标移出画布就收不到事件
```

拖拽时鼠标一旦离开画布边缘，事件中断，节点/视图卡住。

### 问题3：用了 `mousedown/mousemove` 而非 Pointer Events

- 触屏设备不触发
- 触控板手势不稳

## 二、修复

### 2.1 改写成 Pointer Events + 双模式拖拽

```javascript
let pan = null;      // 拖画布时的起点
let downPt = null;   // 按下坐标（判断点击 vs 拖拽）
let moved = false;   // 是否发生有效移动

canvas.addEventListener('pointerdown', (ev) => {
  const p = toGraph(ev);
  const n = pick(p);
  if (n) {
    drag = n;                                    // 按在节点上 → 拖节点
  } else {
    pan = { x0, y0, vx0: view.x, vy0: view.y };  // 按在空白处 → 拖画布
  }
  canvas.setPointerCapture?.(ev.pointerId);      // 捕获指针
  ev.preventDefault();
});

// 关键：绑在 window 上，移出画布也不断
window.addEventListener('pointermove', (ev) => {
  if (pan) {
    view.x = pan.vx0 + (ev.clientX - pan.x0);    // 平移
    view.y = pan.vy0 + (ev.clientY - pan.y0);
    return;
  }
  if (drag) { drag.x = p.x; drag.y = p.y; /* 拖动节点 */ }
});
```

### 2.2 区分「点击」与「拖拽」

```javascript
// 位移 < 4px 视为点击
if (dx * dx + dy * dy > 16) moved = true;

// pointerup 时
if (drag && !moved) { selected = drag; onSelect(drag); }   // 点击选中
if (pan && !moved)  { selected = null; onSelect(null); }    // 空白点击取消选中
```

### 2.3 加平移边界，防止把图拖丢

```javascript
const lim = Math.max(w, h) * 1.2;
view.x = Math.max(-lim, Math.min(lim, pan.vx0 + dx));
view.y = Math.max(-lim, Math.min(lim, pan.vy0 + dy));
```

## 五、教训

| # | 教训 |
|:---|:---|
| 1 | **界面提示是承诺**。提示写了「拖拽移动」但功能没实现，用户按提示操作就会失败。写提示前应先确认功能存在。 |
| 2 | **`mousemove` 要绑 window**。绑在元素上，拖拽出界就断。 |
| 3 | **Pointer Events 优于 Mouse Events**。一套代码同时支持鼠标/触屏/触控笔。 |
| 4 | **拖拽必须区分点击**。否则「拖一下松手」会被误判为点击，触发选中。用位移阈值（4px）区分。 |
| 5 | **拖拽要有边界**。没有边界约束时，用户可能把图拖到视口外，再也找不回来（只能刷新）。 |
