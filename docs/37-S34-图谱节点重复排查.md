## 三、最可能的原因：浏览器缓存了旧 graph.json

`api()` 原本是裸 `fetch`：

```javascript
async function api(path) {
  const r = await fetch(path);   // ← 会被浏览器 HTTP 缓存命中
  ...
}
```

图谱数据在 S28 做过大规模重建（120 → 350 节点），
如果浏览器缓存着旧 `graph.json`，页面会渲染**旧数据**。

旧数据来自更早的构建脚本，那份脚本对人物去重的处理不如现在严格 ——
很可能就是那时留下的重复。

> 注：无法回溯验证，因为旧 `graph.json` 已被覆盖，项目也没有 git 历史。

## 四、三层防护（已实施）

### ① 数据层：构建时断言

`s28_1_build_graph_v2.py` 增加唯一性校验，**有重复直接让构建失败**：

```python
_ids   = [n["id"]   for n in gnodes]
_names = [n["name"] for n in gnodes]
assert len(_ids) == len(set(_ids)), f"存在重复 id: ..."
assert len(_names) == len(set(_names)), f"存在重复 name: ..."
log(f"唯一性校验: {len(_ids)} 个 id / {len(_names)} 个 name 均唯一 ✅")
```

实测输出：
```
唯一性校验: 350 个 id / 350 个 name 均唯一 ✅
```

### ② 接口层：绕过浏览器缓存

```javascript
async function api(path) {
  // 加时间戳 + no-store：数据文件常被浏览器缓存导致显示过期
  const sep = path.includes('?') ? '&' : '?';
  const r = await fetch(path + sep + '_=' + Date.now(), { cache: 'no-store' });
  ...
}
```

这一条顺带解决了一整类问题 —— 之前「统计数字过期」「图谱数字过期」
反复出现，有一部分就是缓存导致的。

### ③ 渲染层：防御性去重

```javascript
function rebuild() {
  // 同一人物只保留一个节点（优先保留度更高的）
  const _seenName = new Set(), _seenId = new Set();
  const nodes = g.nodes
    .filter((n) => activeFams.has(n.family))
    .slice()
    .sort((a, b) => (b.degree || 0) - (a.degree || 0))
    .filter((n) => {
      if (_seenId.has(n.id)) return false;
      if (_seenName.has(n.name)) return false;   // 同名视为同一人
      _seenId.add(n.id); _seenName.add(n.name);
      return true;
    });
```

即便将来数据又出问题，界面上也不会画出两个同名节点。

## 五、你需要做的

**强制刷新浏览器**，清掉缓存的旧 `graph.json`：

| 方式 | 操作 |
|:---|:---|
| Windows | `Ctrl + Shift + R` |
| 或 | `Ctrl + F5` |
| 彻底 | F12 → Application → Storage → Clear site data |

刷新后应该只有一个「薛宝钗」。

### 如果刷新后仍然有两个

说明是渲染层的另一个原因，请提供：

1. 分别点击两个「薛宝钗」，看右侧详情面板的 **度 / 提及次数** 是否相同
   - 相同 → 同一节点被画两次（渲染 bug）
   - 不同 → 数据里确实有两个（数据 bug）
2. 浏览器控制台有无报错

## 七、教训

| # | 教训 |
|:---|:---|
| 1 | **数据可视化的重复问题要看两层**：数据里有几个 vs 画了几个。这次数据层是干净的，问题在缓存。 |
| 2 | **裸 `fetch` 会吃到 HTTP 缓存**。数据类接口应该显式 `cache: 'no-store'` + 时间戳。 |
| 3 | **构建脚本要有断言**。唯一性这种硬约束，让脚本跑挂比让用户发现好。 |
| 4 | **还是没有 git**。这次无法回溯「旧 graph.json 到底有没有重复」，只能推测。 |
