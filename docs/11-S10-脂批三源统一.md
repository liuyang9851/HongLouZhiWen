| 类型 | 条数 | 说明 |
|:---|---:|:---|

但 **S7 把三版本正文入索引时，只处理了 `chapters_*.jsonl`，完全没看批语文件**。

同理 `zhiyanzhai_pizhu/pizhu.jsonl`（9,156 条）也一直躺着没被索引。

## 三、跨源去重

### 3.1 去重策略

```
文本指纹 = 去空白 + 去标点后的文本
保留优先级：抚琴居校本(1) > 癸酉本(2) > 脂批大全(3)
```

**为什么这个优先级**：
- 抚琴居校本：有 PDF 码点重解码的版本归属（甲戌/庚辰/蒙府…），**最可信**
- 癸酉本：该书独有批语，**无法由别处替代**，必须保留原样
- 脂批大全：独立汇编，作补充

### 3.2 重叠实测

```
抚琴居 ∩ 脂批大全 = 1,416 条   ← 主要重叠，都是脂评本系统
抚琴居 ∩ 癸酉本   = 1 条
脂批大全 ∩ 癸酉本 = 3 条
三源都有的        = 1 条
```

去重结果：**12,613 → 9,193**（合并重复 3,420 条）

被合并的记录信息不丢：保留项的 `alt_sources` 字段记下其他来源。

## 四、按真实来源隔离

### 4.1 新增隔离版本 `zhipi`

原来脂批的 rowkey 一律是 `fuqinju|pizhu|…`（把脂批大全和癸酉本也塞进抚琴居，错误）。

改后：

| 隔离版本 | 含义 | 条数 |
|:---|:---|---:|
| `fuqinju/pizhu` | 抚琴居校本内的脂批 | 3,217 |
| `guiyouben/pizhu` | 癸酉本自带批语 | 222 |
| `zhipi/pizhu` | 脂批大全（独立汇编） | 5,754 |

rowkey：`<ver>|pizhu|<hui:03d>|<chunk_id>`
倒排：`<ver>|pizhu|<bigram>`

### 4.2 检索隔离规则

| 选中正文版本 | 参与检索的脂批来源 | 理由 |
|:---|:---|:---|
| 抚琴居校本 | 抚琴居脂批 + 脂批大全 | 都是脂评本系统，互补 |
| 程高本 | **无** | 程高本是删改本，没有脂批 |
| 癸酉本 | 癸酉本批语 | 癸酉本独有 |
| 不限版本 | 三源全部 | — |

代码实现（`backend/app.py`）：

```python
PIZHU_SOURCES_FOR = {
    "fuqinju":   ["fuqinju", "zhipi"],
    "guiyouben": ["guiyouben"],
    "chenggao":  [],
    None:        PIZHU_VERSIONS,
}
```

| # | 局限 |
